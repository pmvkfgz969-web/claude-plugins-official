Avant de commencer : consulter des données à jour

Les demandes sont stockées dans le fichier parking614-data.js, situé dans le même dossier réseau que cette page. Tous les utilisateurs partagent ce fichier.

  • Ouvrez toujours la page depuis le dossier réseau, avec Microsoft Edge ou Google Chrome. N'utilisez jamais une copie enregistrée sur votre poste, dans Téléchargements ou reçue en pièce jointe : elle afficherait des données périmées ou introuvables.
  • Les places libres se mettent à jour seules à l'ouverture, toutes les minutes, et à chaque vérification de disponibilité.
  • Pour forcer la mise à jour, cliquez sur « Actualiser » dans la bande bleu clair sous l'en-tête, ou appuyez sur F5. La date de dernière mise à jour y est affichée.
  • Si un message rouge « fichier de données introuvable » apparaît, vérifiez que parking614-data.js est bien dans le même dossier que la page et que vous avez accès au dossier réseau (connexion ou VPN), puis cliquez sur « Réessayer ».
  • Connexion : utilisez votre login prenom.nom@dachser.com. Mot de passe perdu ? Cliquez sur « Mot de passe perdu ? » sur l'écran de connexion : un brouillon de mail à l'attention de l'administrateur s'ouvre.
  • Autoriser l'enregistrement (une fois par poste) : cliquez sur « Autoriser l'enregistrement » dans la bande sous l'en-tête, sélectionnez le fichier parking614-data.js du dossier réseau, puis acceptez « Modifier le fichier ». Sans cela, aucune demande n'est enregistrée. Le bouton réapparaît si le navigateur redemande l'autorisation.

Cette aide est consultable à tout moment via « Aide : données à jour ».
